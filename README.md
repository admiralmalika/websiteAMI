## 🚀 Panduan Upload ke GitHub & Vercel

1. **Inisialisasi Git & Commit**:
   ```bash
   cd admiral-malika
   git init
   git add .
   git commit -m "Initial commit Admiral Malika Ecosystem (CMS, StoreAdmin, Hybrid Payment)"
   ```

2. **Push ke GitHub Repository**:
   ```bash
   git remote add origin https://github.com/USERNAME/admiral-malika.git
   git branch -M main
   git push -u origin main
   ```

3. **Deploy ke Vercel (Override Project v0.dev)**:
   - Buka dashboard [Vercel.com](https://vercel.com).
   - Hubungkan (*Import*) repositori GitHub `admiral-malika`.
   - Pilih project v0.dev Anda untuk di-override/update.
   - Vercel akan otomatis mengenali `vercel.json` dan melakukan deployment.
